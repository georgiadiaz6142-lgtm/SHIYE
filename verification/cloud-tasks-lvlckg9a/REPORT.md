# 云端任务与清理入口：本地验证

日期：2026-09-11。Song 授权继续部署适配。本轮完成代码和本机集成验证，尚未部署。

## 本轮结果

- 新增持久任务待发送记录，与文案次数预留／抠图任务写在同一个条件更新对象中，提交失败不会只留下其中一半。输入及执行资格用现有服务端加密机制保存；网关消息只有签名任务编号。
- 云任务模式下，公开 API 等待任务通知后返回 202，不在返回后启动进程内 AI 队列。独立 worker HTTP 应用等待实际工作及结果落库完成才返回 204，没有公开网页、账号或管理路由。
- 网关通知只接受异步入口的 202；限制 4 秒、禁止重定向，不自动重复 POST。通知丢失或响应不确定时，待发送记录保留，由维护入口再次投递任务编号。
- 任务执行领取具有独立标识和 180 秒期限。重复投递不重复执行；进程中断后总计最多领取 3 次，业务层仍根据已记录的供应商派发标识拒绝重复 AI 调用。此机制不承诺供应商恰好执行一次：派发确认不明时可以停止并报告未知，而不自动重试供应商。
- 执行资格不保存原始 Cookie：账号使用会话摘要，邀请使用编号／版本／期限。执行前核对最新会话、密码版本及邀请码状态。注销会话、改密码、停用或绑定邀请码后，尚未派发的任务停止。抠图在实际供应商派发事务中再次复核资格。
- 排队期限为 15 分钟。维护回收过期的加密输入、清理 24 小时前的文案预览、处理失效任务；每轮最多通知 10 项任务、删除 100 个已登记且过期的临时媒体。清理失败保留待清理记录，且不阻止独立的积压任务通知步骤。
- 本机模式保留；没有改变前端排布、交互、用户作品、实际 API 配置或现有开发服务。

## 云端仍需完成

1. 官方 TOS SDK 实例化、禁用条件写入的隐式重试、私有桶与最小权限、真实条件写入冲突及服务重建验证。本轮使用共享对象测试替身，不能替代这些检查。
2. 将本轮 `workerApp` 与云存储接入实际启动入口，配置独立异步 Webserver 应用。当前 `server/index.ts` 仍保持原本机启动路径，production 保护未解除。
3. 新建异步应用时选择模式（官方不支持创建后转换），使用弹性实例、无预留、平台重试 0；确认费用后才创建／发布。复用已授权的 hydrogen-gw，但只增加拾页独立入口。
4. 配置网关在任务入队前鉴权／限流及日志脱敏。本轮 worker 签名阻止未授权业务执行，不能阻止公开异步网关先接收垃圾请求产生平台开销。
5. Timer 消息可使用专用维护签名，需真实核对 Native Timer 的 HTTP 路径与消息传递格式；目前验证的是本机 POST `/` 契约，尚未创建 Timer。建议初始每分钟一次、关闭重叠和平台重试，成本须计入最终报价。
6. 配置临时前缀的生命周期（含写入中断遗留对象、非当前版本及删除标记），并核对实际保留时间。应用清理仅处理登记过的过期媒体；不会自动清理未引用的作品图片或历史对象版本。
7. 管理 API 测试凭证仍有进程内状态、生产作品同步状态声明、Linux Node 22 构建、真实网关与浏览器验收也尚未完成。不能将本轮测试结论解释为可以立即正式上线。
