# 手工裁切布局整理 · 2026-09-09

按 Song 的要求，将手工裁切从右侧双栏面板改为完整宽度图片与下方操作区。图片高度上限由 450px 放宽到视口高度的 80%，不再为侧栏压缩宽度。

按钮整理：撤销、恢复撤销相邻排列，清除选区位于工具栏最后；只在有待完成轮廓时显示“完成圈选”。完成圈选后直接显示可拖动边界点，省去重复的“调整边界”按钮。单个选区不显示选区切换和重复的移除入口；多个选区仍可切换和移除当前选区。返回自动贴边、换照片归入次要操作，确认预览单独突出。去掉原操作面板的大标题、英文标记与长说明，保留简短操作提示。

验证：隔离 Chrome 1440、390、320 px 全部通过；图片与工具栏位置、全宽、按钮顺序、圈选、边界点微调、撤销／恢复、清除后撤销恢复、预览和素材保存均检查，无页面异常或横向溢出。桌面和 390 px 截图已查看。机器结果及截图位于 `run-01/`。仅使用项目山湖示例，未调用百度、未操作用户浏览器数据。真机 Safari 未测。

本轮仅修改 `shiye-editorial-prototype/edgecut.js` 和 `edgecut.css` 的手工模式布局；抠图算法及手帐编辑逻辑未改。
