【已完成】按 Song 确认加入完整默认提示词、管理员编辑/保存/恢复默认，以及编辑器字号设置。本轮沿用 `feat/ai-copy-20260910`，修改前节点为 `0c48e45`。

## 使用入口

- **管理工具 → API 管理 → AI 手账文案 → 提示词设置**：查看已确认的完整提示词，编辑并保存；显示最近修改时间及修改者。“恢复默认”填回默认文本，再点“保存提示词”生效。
- **书页编辑 → 选中文字 → 文字 → 字号**：修改当前文字字号。未选中文字时设置新文字的默认字号，随后点击纸面或“添加文字”输入。
- 选中文字的工具栏、编辑文字对话框也提供字号设置。范围为 1～500 px；旧文字通过缩放得到的小数字号保留，单纯打开文字编辑再保存不会取整。

## 实现与边界

提示词单独保存至运行目录 `ai-copy-prompt.json`，无需配置 API 即可管理。没有自定义配置时使用代码内置的已确认版本。保存含修订号校验，避免旧后台覆盖新修改；记录管理员审计。普通账号不能读取或修改。供应商请求从服务端读取提示词，已准备请求保留原提示词，后续新请求采用新版本；原预览与书页不重写。

字号写入现有结构化文字的 `size` 字段，保持位置、宽度、方向、字体与旋转。修改支持撤销、重做、本机自动保存和现有账号同步。文字面板在选择变化时刷新对应字号；新手写与新 AI 文字沿用本次页面会话选择的新文字默认字号。新文字默认值与原字体选择一致属于当前页面会话设置，已放入书页的字号永久随作品保存。

未接入新供应商、未启用真实文案、未发出付费模型请求。提示词格式与原有 JSON 结果校验分开：管理员修改提示词不会绕开服务端结果校验。
