# 书名旁的更多菜单 · 2026-09-09

按 Song 确认的方案移除书架卡片下方常驻的置顶、改名、删除按钮和分隔线，在书名同行右侧放置「⋯」。点击弹出置顶／取消置顶、重命名、删除，删除单独分隔且使用较淡红色，仍沿用一次删除确认。已置顶仅显示小图钉。封面单击打开手帐保持不变。

使用原生 popover，在空间不足时向上展开；点击外部、Escape、滚动或窗口变化关闭。菜单动作沿用已验证的置顶、重命名、删除与保存处理，不修改编辑、跨页、文字输入、字体或作品结构。

修改文件：`shiye-editorial-prototype/app.js`、`styles.css`。修改前归档：`../../archive/20260909-170759-before-shelf-menu.tar.gz`。

验证：JS 语法通过；隔离 Chrome 的 1440、390、320 宽度检查通过，包括默认隐藏、菜单位置不出屏、外部/Escape 关闭、置顶/取消置顶、重命名、删除确认与取消、封面进入阅读。已查看桌面和手机的菜单开关截图。首次脚本过早读取异步 toggle 状态，改为等待原生事件后通过，产品实现未因此修改。截图查看后将更多入口换成更清楚的「⋯」文字符号。

证据：`results.json`、`closed-*.png`、`open-*.png`。检查仅使用独立浏览器测试数据和本机 GET 请求；未接触用户作品或部署。真实手机、Safari 未验证。
