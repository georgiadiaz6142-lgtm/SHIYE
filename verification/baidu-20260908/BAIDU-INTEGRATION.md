## 本次结论

【已确认/现场事实】在现有 TypeScript 后端及同一个贴纸工坊中实现百度自动抠图、框提示补提/重提、透明预览和原收藏流程。没有新增依赖或另一套后端。Song 已在本机填入两项密钥，仅检查过字段非空；有效性、接口权限和免费额度均未通过真实请求验证。

本轮测试使用隔离合成图片、虚构凭据和内存中的供应商响应。真实百度网络请求为零；这些结果只能证明工程流程，不能证明分割质量。本次没有修改 `.env.local`、上传 Song 的照片、付费或部署。

【已确认/官方接口事实】百度的 `auto` / `control` 接口返回一张结果图；`control` 支持框提示，未提供正负点或圈线字段。实现请求 `return_form: mask`，用原图像素与返回蒙版合成贴纸。[百度 API 文档](https://ai.baidu.com/ai-doc/IMAGEPROCESS/rm8zl3koj)

【尚未确认】自动结果可能包含多个物体；此版本显示一个“自动前景（可能含多个物体）”候选，不将合并前景伪装成独立多主体发现。框选结果是否贴边、相邻对象能否独立提取、细节质量、时延和计费仍待真实小样。第一阶段原有多主体/纠错验收标准保持不变。

## 代码与行为

- `server/baidu.ts`：固定 HTTPS 端点、服务端获取并仅在内存缓存 Token；拒绝跳转，限制响应体与超时；不回显上游原文或凭据，不自动重试。保留 uint64 请求编号，不转换成有精度损失的数字。
- `server/images.ts`：校验原文件不超过 10 MiB、静态 JPEG/PNG/WebP、解码不超过 2400 万像素，方向规范化、最长边不超过 2000。规范化后最短边需至少 128，PNG 的 base64 不超过 10,000,000 字节，否则明确拒绝；不通过静默改画质来绕过限制。
- `server/jobs.ts`：复用任务、版本、幂等和文件存储；百度请求前持久化一次尝试，按本轮上限阻止继续提交；超时、取消、重启不自动重发。成功候选带百度请求编号，成本为 CNY / null（待核对），不假记为免费。
- `server/app.ts`：新增 `POST /api/uploads/photo` 原始二进制上传，沿用本机会话与来源保护；授权与逐张同意检查先于读取图片。原模拟 init 路径保留，原 PUT 路径保持拒绝。
- `shared/contracts.ts`：新增严格的归一化框和百度来源字段；保留 schemaVersion 1 对旧模拟记录的可读性，不迁移浏览器数据。旧程序回退前需使用对应旧运行目录，不让旧代码加载新百度任务数据。
- `shiye-editorial-prototype/segmentation.js`：同一工坊按后端模式显示；真实模式先选文件、勾选本张照片交给百度处理，再主动提交。框选是模型提示，不按矩形裁切。百度模式不显示不支持的点/圈线修正。
- `shiye-editorial-prototype/app.js`：更新入口与来源文案，收藏提示区分模拟贴纸；原小剪刀、纸样、软翻页和首页样式不改。

所有供应商蒙版都经过 PNG、尺寸、灰度和非空有效区域检查；透明贴纸只使用规范化原图 RGB 与蒙版 alpha。白边在本地合成，不再次请求模型。新增照片属于明确配置 TTL 下的临时文件；不触碰已有作品或恢复归档，不声称本地清理会删除百度端数据。

## 真实测试启用前的配置门槛

当前 `.env.local` 保持 `SHIYE_SEGMENTATION_MODE=mock`，启动、健康检查及模拟流程不会读取或提交照片到百度。新增变量只写入无密钥的 `.env.example`。

只有 Song 确认 API 额度、测试照片范围及保留期限后才配置：

| 配置 | 要求 |
| --- | --- |
| `SHIYE_SEGMENTATION_MODE` | `live` 才允许启用百度；默认 `mock` |
| `BAIDU_API_KEY`、`BAIDU_SECRET_KEY` | 由 Song 本地填写；不进入浏览器、报告或归档 |
| `SHIYE_BAIDU_APPROVED` | 必须显式为 `true` |
| `SHIYE_BAIDU_MAX_CALLS` | 本轮运行目录内累计尝试上限，整数 1～100；失败与不确定请求也占用上限，不等于百度账单或免费余额 |
| `SHIYE_BAIDU_APPROVED_UNTIL` | 带时区的明确未来时间；到期后拒绝新上传/请求 |
| `SHIYE_TEMP_TTL_SECONDS` | 显式本机临时保留期限，60～86400 秒；不代表百度端保留期限 |
| `SHIYE_RUNTIME_DIR` | 静态根目录外的专用私有运行目录；不得为绕过次数限制更换目录 |

尚未启用这些配置，也没有鉴权请求。真实请求的成本需与控制台核对；超时或重启后的状态不明时先核对记录，不点击重新提交来猜测。
