# 贴纸预览尺寸与悬停边界 · 2026-09-10

## 范围与恢复节点

Song 授权先保存节点，保留悬停放大，统一可见主体缩放并避免越界。[前置节点](../../archive/20260910-220505-before-sticker-preview/README.md) 包含 1706 个文件及已有未提交修改，逐文件 SHA-256 已核验；不含密钥、私人运行数据、用户作品、依赖或旧归档。继续使用当前前端加固分支。

## 实现

- 卡片图片改为绝对定位的固定预览槽，避免原生图片尺寸撑开百分比网格。四边留白 12%，默认旋转 -3°；悬停旋转 3° 并放大 1.06 倍，阴影和收藏标记保留。卡片设置溢出保护，专项检查同时验证可见内容的变换边界实际在框内，而非仅依靠裁掉溢出。
- 新增 sticker-preview.js，仅对仓库及编辑器贴纸工具中的预览生成临时 PNG：最长边 1024 的 alpha 扫描，保留所有非零透明度内容及采样留白；结果最长边 512。原始文件、资产数据、书页元素、插入尺寸、导出数据均不修改，不上传图片。
- 预览缓存最多 32 项，身份切换清空，异步结果校验代次和图片来源。不可读取或全透明图片沿用原图 contain 兜底，不阻断操作。原素材中的实际可见背景、草地、装饰或杂点仍会保留；本功能只去透明留白，不做语义识别或重新抠图。
- 新模块纳入 strict/checkJs 检查与静态资源白名单。
