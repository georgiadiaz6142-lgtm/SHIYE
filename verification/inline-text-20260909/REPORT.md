# 纸面原位文字输入

2026-09-09 · 已实现，最终浏览器结果 run-04。

## 行为

- 编辑模式点击/轻点纸面空白处，直接出现无边框输入光标；不先画框、不弹出添加对话框。
- 双击现有文字可原位输入；单击选中和拖动移动保留。文字工具中的添加入口也直接在纸面开始输入。
- 点击别处、Escape 或 Ctrl/Cmd+Enter 结束输入，Enter 换行。未输入内容的空白点选不产生文字对象；清空已有文字并结束输入会移除空文字，可撤销。
- 文字仍作为原有结构化元素保存，每个输入会话归为一次作品撤销。输入阶段保留原生光标/文字选择/删除行为，最多 800 字。原有字体与方向设置入口保留。
- 合成输入结束后同步正文，500ms 既有本机保存机制继续生效；结束输入同步缩略图和撤销按钮状态。存储失败保留输入，既有保护阻止切换翻阅。
- 翻阅模式不会启动输入，空白拖动不触发输入。
