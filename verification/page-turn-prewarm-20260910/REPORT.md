# 相邻页空闲预缓存验收 · 2026-09-10

## 范围与结论

Song 已确认“目前已看不到白缝”。本轮保持接缝、阴影、翻页曲面和动画时长，只减少首次翻页临时准备页面图片的等待。产品改动位于 `shiye-editorial-prototype/app.js`、`styles.css`，沿用现有最多 6 面的临时内存缓存，不新增持久化、依赖或供应商调用。

停下操作 500ms 后，利用浏览器空闲时间逐面准备前后相邻翻页所需的正反面。按住鼠标/触摸、纸面输入、翻页中或页面不可见时不开始后续准备；退出页面或切换身份会取消队列。已经启动的单面异步捕获会完成并移除隐藏节点。隐藏节点独立于真实翻页层，不改变书页尺寸、选择或布局。HTML 先按浏览器规则规范化，确保预缓存与正式翻页命中同一项；内容、尺寸或像素密度变化使用新的缓存项。

## 实测

隔离本机服务 + 无头 Chrome，1440×1000，每页 24 个文字元素。相同书页、同一轮内清空缓存后与预热后比较：

| 指标 | 未预热 | 相邻页预热后 |
| --- | ---: | ---: |
| 创建翻页层到动画准备就绪（包括布局与切片） | 99.8 ms | 61.4 ms |
| 两面图片缓存读取/生成 | 39.1 / 38.6 ms | 0 / 0 ms（计时精度内） |

这是一组本机采样，不是所有设备的性能保证。预热后的正面 PNG 与同尺寸现场捕获 PNG 完全相同。用户在空闲准备完成前立刻翻页，仍使用原有现场捕获与失败回退，不会保证零等待。
