# 书架置顶、删除入口与双页编辑 · 2026-09-09

## 已完成（本机原型）

- 书架提供常显的「置顶／取消置顶」「改名」「删除」文字按钮。置顶优先于最近编辑和书名排序，随手帐保存。删除从书架直接进入一次确认，列出书名、页数与不可恢复说明；取消保留，保存失败时恢复内存中的手帐并允许重试，不误报删除成功。贴纸收藏不受影响。
- 编辑页新增单页／双页切换，选择随手帐保存。双页左右两侧都能直接输入、修改文字和放置贴纸；原字体选择保留。单页编辑仍使用原有输入过程。
- 纸张面板可选择左右分别选纸，或一张铺满双页。独立纸张的原选择保留，退出整幅背景时恢复。图片按整幅双页铺设，单页、缩略图和翻页面仅显示对应半幅；点阵、方格、横线保留原纹理间距。
- 新贴纸默认范围可选择「只在一页内／允许跨书缝」，已有贴纸也能单独切换。跨页贴纸保存为一个元素，以另一页 ID 关联，在各纸页内裁切显示。支持从面板直接拖到另一页或书缝，以及从右侧投影拖动原对象、旋转、缩放和撤销。限制页内时按旋转后的边界收回所属页。
- 编辑和阅读共用固定的书页配对。旧书默认首页独立，后面两页一组；首次首页双页视图提供「新建双页」，只有左页时可「添加右页」，页面工具也提供「新增双页」。既有作品不会因切换视图被自动加页。
- 排序按固定配对整组移动；复制双页时重建页与元素 ID，跨页贴纸只关联新复制的那一组。有关联背景或跨页贴纸的双页，删除确认会明确告知整组删除，可撤销恢复。没有关联内容的页面可以单独删除，不重新配对其他页。

## 实现与保护

产品文件只修改 `shiye-editorial-prototype/app.js`、`shiye-editorial-prototype/styles.css`。书架字段 `pinned`，编辑偏好 `editorLayout` / `stickerPlacement`；页面字段 `spreadKey` / `spreadSide` / `paperSpread`；跨页贴纸字段 `spreadWith`。这些结构随原 IndexedDB 事务保存，兼容旧书；页内容仍使用既有撤销历史。
