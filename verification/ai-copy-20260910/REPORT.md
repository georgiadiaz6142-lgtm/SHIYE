## 已实现

1. 编辑器“文字 → AI 帮我”，选中文字后的“帮我润色”。自填主题或草稿，可补充日期、地点、心情，选择自然、温柔、简短语气。现有纸面点击输入和字体逻辑保留。
2. 仅向模型发送当前选中页的贴纸合成缩略图（JPEG，398×512）及用户填写字段。不会附带整本手账、其他页正文、原始照片或定位元数据。跨页贴纸只呈现当前页可见部分。
3. 文案先预览，可修改、再生成、明确放入。生成成功后收起填写区，避免遮住操作按钮。润色保留原文字的位置、字号、字体、方向、颜色和旋转；新文案添加为正常文字元素。支持撤销、重做、原位编辑和既有自动保存/同步。
4. 文本保存 AI 来源（任务、供应商、模型和生成时间），手动修改后仍保留来源。应用前重新检查账号、页面和内容版本；当前页或另一侧持有的跨页贴纸变化时，旧结果不能覆盖新内容。
5. 服务端持久任务和额度：邀请码累计共享 3 次；普通账号每上海自然月 10 次；有效会员总额度 100 次，非额外加 100。注册当月承接关联邀请码已用次数；跨月邀请码累计不重置。会员到期字段为服务端预留，本轮未添加会员兑换或开通入口。
6. 有效生成结果计 1 次，重新生成使用新任务计次；同任务重放只返回原结果。失败、超时和重启中断不扣用户次数。请求中占用额度，防止并发超扣。断线通过原任务 ID 查询，不自动重新发起供应商调用。
7. 独立火山方舟适配器；管理员可以配置密钥、模型 ID、累计请求上限、截止时间及可选单价。保存不发起鉴权或模型请求。配置与成功预览加密存储，管理端不返回密钥。普通用户无配置和调用记录权限。
8. 用户次数与供应商账单分开：所有已派发请求计入全局请求上限，包括失败和超时；记录返回的 Token 用量，配置单价后估算金额，缺少用量或单价显示未知。实际费用以供应商账单为准。配置变更记录管理员审计。

方舟请求格式依据官方 SDK 的图片内容和结构化输出类型；具体模型是否同时支持图片输入与 JSON 输出仍需选定后实测。参考：[官方 Go SDK 类型](https://pkg.go.dev/github.com/volcengine/ark-runtime-go/arkruntime/model/chat)、[官方客户端实现](https://github.com/volcengine/ark-runtime-go/blob/main/arkruntime/client.go)。本轮没有把协议适配测试等同于真实模型质量验收。

## 已知边界与下一步

- 【未验证】真实模型生成质量、模型权限、价格和真实 Token 账单。管理员尚未配置文案密钥/型号或启用；本轮真实文案 API 调用为 0。
- 下一步先选定支持图片输入与结构化输出的方舟模型，确认价格和少量真实验收的调用范围，再启用并以指定素材验收。已有百度授权不自动扩展到文案模型。
- 成功预览可查询 24 小时，过期后不再返回正文；启动时清理过期预览密文，额度和费用记录继续保留。浏览器用账号/书页分区的 sessionStorage 保存原请求用于本标签恢复；清除浏览器存储或新标签不会自动恢复未应用预览，已应用文字仍按作品同步。
- 文案账本与配置沿用本机单进程开发存储；上火山引擎前需接入持久共享数据库及部署鉴权配置。本轮没有部署、开存储桶或改变已有云资源。
- 未测试 Safari/手机硬件。本机服务重启会使内存登录会话失效，必要时重新登录；作品和账号资料保留。
- 原有未跟踪归档、历史截图、真实账号资料及百度配置均未纳入本轮代码提交。
