# 翻页内容延迟出现修复 · 2026-09-10

## 已确认的原因和修复

Song 反馈湖景示例中的大照片、胶带/贴纸翻页时没跟上、结束后才出现。本轮使用同款 `samplePage('lake')`，在隔离 Chrome 中延迟图片响应复现：快照读取图片尺寸时图片尚未解码，自动高度为零，照片被捕获成一条相框细边。缓存继续复用这张缺少内容的图片；动画结束恢复真实页面时，才显示完整照片。

对照：[修复前背面图片](./slow-texture-1.png)、[修复后完整图片](./complete-texture.png)。上述问题已复现；不能因此断言用户所有设备上的卡顿或纸张手感都来自这一个原因。

`shiye-editorial-prototype/app.js` 的共同页面捕获入口改为先等待所有照片和 SVG 贴纸解码，再读取布局尺寸。读取失败或超过 1200ms 时拒绝此次捕获，沿用原有失败移除缓存及两面原始内容回退，避免永久复用不完整快照。离页后不再捕获已移除节点。首页、阅读、单页/双页编辑及空闲预缓存共用此入口。

本轮未修改立体曲线、阴影或动画时长；先解决“内容翻完再补上”的明确问题。没有新增依赖、修改账户配置、调用真实供应商、部署或操作用户作品。原有未提交改动保留。
