# 主按钮边缘高光

2026-09-11，按 Song 提供的 Vue Bits SpecularButton 源码说明和 https://vue-bits.dev/components/specular-button 适配。

## 实现与范围

当前前端为原生 JavaScript。本轮采用独立原生模块与 CSS 遮罩渐变，适配双侧边缘高光、250px 接近渐亮和鼠标方向平滑跟随；不是直接运行 Vue/OGL 组件，渲染结果不承诺与原 shader 逐像素相同。未增加依赖、WebGL 上下文或持续自动旋转。

- 覆盖主要 primary/dark 按钮、保存并用于创作、首页开始创作/登录按钮、房间有声/无声入口及管理页主按钮。
- 排除输入框、工具图标、普通选项、删除按钮、登录后的圆形头像。禁用按钮不显示高光。
- 保留按钮尺寸、颜色、文字、圆角、点击事件和原有键盘焦点；仅追加不接收指针的装饰边缘。
- 动态弹窗、新渲染按钮和按钮标签替换自动适配；减少动态效果设置关闭装饰；不支持 CSS 遮罩时回退原按钮。
- 新文件 `specular-buttons.js`、`specular-buttons.css`；三个 HTML 入口加载模块；服务公开文件白名单增加这两个具体文件。
