# 本机管理员后台验收 · 2026-09-09

## 已完成

- 独立管理员用户名／密码登录，入口 `http://127.0.0.1:4176/admin`。普通界面仅管理员显示“管理工具”；服务端鉴权覆盖全部管理数据与修改接口。
- 后台包含概览、API 管理、邀请码管理、操作记录。支持退出及修改密码；修改密码使全部管理员会话失效。
- API 管理展示供应商、固定接口地址、掩码凭据、启用状态、最近测试和调用。修改凭据或启用必须先对当前配置进行鉴权测试；失败不覆盖原配置，旧版本保存被拒绝。
- 邀请码支持按批次创建 1～100 个、有效期、备注、搜索与状态筛选、查看完整码、导出筛选结果、停用／恢复。停用作废已签发资格；恢复后需重新验证邀请码，旧凭证不会复活。
- 管理操作留审计记录；记录不含密码、完整邀请码、密钥或图片。
- 密码使用加盐 scrypt，API 凭据与可查看邀请码使用 AES-256-GCM 加密。管理员 Cookie 为 HttpOnly／SameSite Strict，有效期 8 小时；本机服务重启使会话失效。JSON 修改按文件串行、临时文件同步后原子替换。

## 边界

- 当前 API 适配器只有百度。更换其他供应商需后续实现适配器，不能只替换 URL。
- “测试连接”只验证百度 OAuth 凭据，不能证明抠图／命名具体接口已开通，也不提交图片。本轮连接测试使用模拟供应商，没有新增真实百度请求。
- 自动命名仍因此前百度功能权限问题保持关闭，本轮未宣称解决该权限。
- 这是本机单进程版本，未部署公网；正式数据库、管理员二次验证及正式账号／注册绑定仍按项目后续计划处理。普通手机号登录仍未开放。
