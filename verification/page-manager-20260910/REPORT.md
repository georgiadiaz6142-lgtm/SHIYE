# 编辑页面管理条 · 2026-09-10

## 完成内容

按 Song 确认的方案，产品代码修改 `shiye-editorial-prototype/app.js` 与 `styles.css`：

- 编辑页底部显示总页数、当前页，点击缩略图切换；两页编辑中直接选择另一侧也同步更新计数。
- 缩略图右上角小“⋯”打开原生浮层菜单，提供前加一页、后加一页、删除；支持点击外部或 Escape 收起。右侧加号在末尾加页。新增页为空白并自动选中。
- 普通页按住拖动排序；手机长按 350ms 激活。普通手机滑动用于滚动列表；排序时显示插入标记，靠近两端自动滚动。取消不修改顺序，松手后不会误触页面跳转。
- 只有使用跨页纸张或跨页元素的页面成组操作。菜单标明关联页，插入位置在整组外侧，拖动任一半都会移动整组，删除一起删除。普通页重新配对以反映新顺序；跨页组保留原左右关系，旧手账的隐式配对会在实际修改事务中固化。页面 ID、内容、跨页引用不重建。
- 删除立即完成，提示条提供 8 秒“撤销”；之后仍可用编辑栏的撤销。至少保留一个操作单元，只有一组关联双页时整组保留。撤销恢复原内容、顺序、配对，快捷撤销不会覆盖后续编辑或其他账号/书本。
- 页面侧栏的前移、后移、新增、删除复用同样规则；移动、插入、删除仍进入既有撤销历史与自动保存流程。
- 手机端也显示底部缩略图，文字工具在其下方独立滚动；桌面右侧工具布局保持。

未修改翻页动画引擎、字体输入、照片/贴纸内容或后端；未安装依赖、提交、创建分支或部署。保留原工作区其他未提交修改。
