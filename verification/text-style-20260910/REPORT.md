# 文字加粗与颜色 · 2026-09-10

已按 Song 要求在书页“文字”面板、选中文字工具栏及“编辑文字”对话框加入加粗和颜色选择。操作作用于选中的整个文字元素；未选中时设置本次页面会话中新文字的默认样式。已有字号和原位输入流程保留。
