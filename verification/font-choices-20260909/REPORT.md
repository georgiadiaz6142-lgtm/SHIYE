# 字体选择 · 2026-09-09

已在现有本机原型加入宋体、黑体、楷体（手写感）、仿宋、圆体。文字面板可为下一段输入选择字体并预览；选中文字后可直接切换，原样式对话框使用同组选项。保留旧 serif / sans / hand 标识，未知值回退宋体。

实际修改：`shiye-editorial-prototype/app.js`、`styles.css`。直接输入函数只将新文字的固定默认字体替换为所选字体，输入事件、中文组合输入、坐标、手势、提交与编辑过程保持原实现。字体变更沿用既有保存与撤销机制。
