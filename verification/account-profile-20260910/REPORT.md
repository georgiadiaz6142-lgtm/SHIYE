# 账户面板与普通账号验收 · 2026-09-10

## 完成的行为

- 桌面与手机头像入口打开账户面板，包含头像、用户名、密码修改、退出、切换账号。
- 头像支持 JPG／PNG／WebP，最大 2 MB；服务端限制解码像素，转为 256×256 PNG，丢弃原图元数据，不接受 SVG 或外部 URL。
- 用户名重名检查覆盖管理员及普通用户，规范化 Unicode 并忽略大小写。改用户名需当前密码；更改后新用户名用于首页账号登录，管理员也可以继续使用专用路径。
- 改密码需当前密码，新密码至少 12 位；撤销此账号的全部登录会话，其他账号不受影响。密码使用加盐 scrypt，不返回给前端或写入前端存储。
- 邀请码验证后可以首次设置用户名、密码，也可暂时跳过。注册时在单个原子更新中创建普通账号并绑定邀请码，已绑定码不能重复开户，旧访客资格失效。普通账号无法进入管理接口，客户端不能提交角色或其他账号 ID 来修改资料。
- 首页账号密码入口支持普通账号和管理员。两者保持固定账号 ID，头像和账户凭据由服务端保存，可在另一个浏览器登录取得同一份资料。

## 本机作品与身份边界

按 Song 本轮明确选择，旧作品首次归入由用户决定。初次新建账号的本机工作区时显示选择：归入当前账号，或保留访客空间；关闭对话框也不会归入。

确认归入时，事务核对访客与目标工作区均未变化，将作品及其 Blob 图片保存到当前账号空间，保留账号下导入备份，并把访客空间恢复为初始示例。若并发发生变化则拒绝覆盖。没有自动上传手账或贴纸。

账号工作区与图片键按固定 ID 隔离。退出前保存、退出后保留但不在访客或其他账号界面展示；同一账号再次登录同一浏览器可以继续编辑。跨标签身份变化先隐藏旧内容，再核验会话并重新加载对应空间。保存失败时保留内存内容、锁定旧界面并允许重试，不把旧快照写入新账号空间。

服务器临时图片归属从纯浏览器 Cookie 调整为已登录账号 ID，访客仍使用浏览器身份。另一账号不能查询前一账号图片会话；同一账号换浏览器可访问仍有效的服务器临时图片。正式手账／贴纸云同步尚未实现。

## 本机更新与限制

更新前确认无活动图片任务，备份账号和邀请码配置到 `.local/account-profile-backup-20260910/`，随后更新原 4176 本机服务。原用户名、用户自设密码、固定管理员 ID、API 配置及既有邀请码保持不变。原用户浏览器数据未由自动化读取或移动，归入操作留给用户自行选择。

真实管理员成功登录未自动复验：没有请求用户提供当前密码，也未重试失效初始密码。完整账户流程使用隔离账号与合成头像测试，没有消耗真实邀请码或调用百度。

手机号验证码接入仍未开放；本轮完成的首次开户入口是邀请码。网站仍仅本机访问，公网部署、短信服务与手账／贴纸云同步不在本轮实现范围内。
