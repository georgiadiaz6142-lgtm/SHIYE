## 交付与变更

- 项目内安装指定版本，共新增 87 个包，生成 package-lock.json：Express 5.2.1、Sharp 0.34.5、Zod 4.3.6、TypeScript 5.9.3、@types/express 5.0.6、@types/node 22.19.15。Node v22.22.3、npm 10.9.8；未全局安装。
- 修复 server/app.ts 的受控图片发送：默认 sendFile 会拒绝 `.local` 隐藏路径，造成任务成功但图片 404。仅在 UUID、会话归属、期限均检查通过的 media 路由允许隐藏目录文件；静态目录白名单不扩大。
- HTTP 测试运行目录改为隐藏子目录，并验证响应能解码为 600 像素宽 PNG，防止仅测非隐藏临时目录漏检。
- app.js 两处贴纸呈现尊重 borderBaked：已经合成白边的 Blob 在手帐和详情中不再叠加白边。旧 data URL 贴纸原逻辑保留。未修改纸样、小剪刀、软翻页、首页、素材或样式文件。
- 新增 http-browser.cjs，沿用原浏览器流程，实际调用本机 HTTP，不拦截伪造 API 响应。外部请求被阻止；浏览器仅使用临时隔离上下文。

## 服务、资产和恢复

4176 仍是原 Python 静态预览。4177 是同一 shiye-editorial-prototype 前端连接本轮模拟后端的本机联调服务，仅监听 127.0.0.1；不是平行原型。启动命令：

```sh
SHIYE_PORT=4177 SHIYE_RUNTIME_DIR=.local/http-verification-20260908 npm start
```

4177 的浏览器 origin 与 4176 不同，不显示旧端口的作品；不得因此认定旧作品丢失。未迁移、导出或操作 Song 的浏览器作品。后端运行文件只有合成测试图片和任务元数据，不作为正式数据库。

原认可节点 `archive/2026-09-08-approved-scissors-confirm-171302.tar.gz` 保留。本轮两个修复前的源码另存 `archive/2026-09-08-before-http-integration-fixes.tar.gz`；归档不包含浏览器作品。源码及锁文件指纹见 [http-source-hashes.json](./http-source-hashes.json)。
