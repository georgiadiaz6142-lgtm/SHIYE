# 公网接入适配与本地验证

日期：2026-09-11。范围：部署前代码适配，不包含云资源创建或发布。

## 已完成

- `runtime-config.ts`：本机默认仍监听 `127.0.0.1:4176`。新增显式 `cloud-test` 配置，可监听网关所需端口与 `0.0.0.0`；要求准确的 HTTPS 来源、独立绝对运行目录及受控初始管理员配置。
- `http-policy.ts`：统一校验 Host、Origin、跨站请求标记和 API 写操作来源；不信任客户端的 Forwarded/X-Forwarded-* 头。HTTPS 由网关终止，网关必须保留公网 Host，不能将 HTTP 后端端口直接作为正式入口。
- 游客、邀请码、账号与管理员 Cookie 的设置和清除统一使用 HttpOnly、SameSite=Strict、Path=/api。公网模式额外启用 Secure；本机 HTTP 仍可正常使用。
- 云端测试管理员支持从受控环境变量初始化，仅持久化密码哈希，不生成明文账号回执。已有管理员身份不会被新的初始化用户名或密码覆盖。
- `createApp` 可以注入已有 `WorkRepository` / `WorkObjectStorage` 接口实现；测试确认作品读取将服务端验证后的账号 ID 交给所选存储。默认仍使用原本机文件实现，没有接入真实云存储。
- `.env.example` 只补充配置说明，未改 `.env.local`、本机账号文件或用户作品，未重启原有开发服务。

## 持久化仍需完成的范围

| 数据 | 当前实现 | 云端适配要求 |
| --- | --- | --- |
| 管理员、账号、邀请码、审计 | admin.json / invites.json 与进程内串行写入 | 持久化存储、事务和跨实例并发控制；保持账号 ID |
| 登录会话、限流 | 进程内 Map | 明确单实例限制或共享会话/限流；不能只信任客户端 IP 头 |
| 作品及图片元数据 | 每账号 JSON、revision 和 operationId | 保留事务、幂等、冲突检查和账号隔离 |
| 贴纸与作品图片 | 账号目录中的 PNG | 私有对象存储；完成校验且写入成功后才提交引用 |
| AI 配置、提示词、用量状态 | 本机 JSON 与管理员加密文件 | 稳定的受控加密密钥、持久化记录及恢复验证 |
| 临时抠图任务与媒体 | 运行目录 | 过期清理、重建后的任务状态处理，不能恢复时假称成功 |

`cloud-test` 必须显式设置 `SHIYE_ALLOW_EPHEMERAL_TEST_DATA=true`，只用于可丢弃数据的技术测试。`production` 模式目前拒绝启动。TOS/数据库尚未连接，`/api/works/status` 继续报告 `cloudConnected:false`。
