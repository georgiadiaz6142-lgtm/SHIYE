# AI 配置、任务与临时媒体持久化：本地验证

日期：2026-09-11。承接 TOS 第一阶段，Song 授权继续 AI 配置、任务与次数记录适配。

## 本次完成

- 文案配置、提示词、文案操作记录可注入同一个对象文档组。沿用现有密钥加密和配置版本保护，任务预留与累计上限检查在一个原子提交内完成。
- 文案任务增加执行标识与期限。新实例启动保留其他实例期限内的任务；过期任务释放用户预留次数，但保留潜在供应商调用记录，不自动再次请求 AI。
- 文案仅在调用领取确认后发起请求。领取响应丢失时不调用供应商。结果保存独立于供应商执行，最多尝试三次保存；已确认的成功不会被保存异常改成失败，迟到结果不能覆盖过期任务。
- 抠图任务及贴纸命名记录可进入对象存储。工作实例通过条件更新领取任务；执行标识、期限、取消状态和已调用标记共同防止重复派发及迟到覆盖。
- 临时媒体可由对象存储保存，独立 temporary 前缀，带 SHA-256 内容校验。业务代码不再直接依赖本机媒体路径。过期清理只有实际删除成功后才移除清理记录；失败可以再次清理。
- TOS 适配接口新增受限临时对象删除入口，只处理 temporary 下的临时文件，不为业务作品提供删除入口。尚未调用真实 TOS。
- HTTP 接口改为读取共享任务状态和媒体；文案、任务、媒体存储通过 createApp 参数注入。内部执行标识不返回给前端。本机默认模式及前端交互保留。

## 明确边界：还没有完成云端上线

1. **云任务执行接线仍是阻断项。** 当前开发入口仍使用内存 Promise/队列及本机定时器，不能假定 veFaaS 在 HTTP 返回后继续运行它们。需接云端执行触发与清理调度，保留现有 202 + 轮询交互；前端文案请求超时目前为 12 秒，不能简单改成等待整个模型调用再响应。
2. 本次提供执行领取和持久化状态，不承诺供应商请求的“恰好一次执行”。调用可能已发送但响应未知时，采用不自动重发策略；调用成功后、结果尚未持久化前进程彻底丢失，仍可能无法恢复该结果，只能报告中断或未知，不能伪造成功。
3. 文案输入不写入操作记录正文，目前只保留指纹。跨进程云工作器执行需要补受控任务输入传递、执行时授权校验与期限，不能把请求上下文闭包当成可持久化任务。
4. 尚未安装/实例化真实 TOS SDK、创建桶、验证云端条件写入、跨进程/云容器重启或实际计费。production 部署阻断保留，index.ts 尚未接对象存储参数。
5. 临时对象需要云端生命周期兜底；并发元数据失败可能留下未引用的临时图片。开启版本控制后还要考虑删除标记及非当前版本保留。后台清理任务失败不能假装已经清除文件。
6. 任务记录、审计、回执的容量/归档策略，以及账号组重复读取开销仍需配置和测量。单对象条件更新不是跨对象事务。
7. API 配置测试证明仍是实例内存数据，跨实例确认与部署迁移仍待完成。
