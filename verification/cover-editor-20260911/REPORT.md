## 已实现

- 编辑页缩略图第一项为“封面”，独立于内页计数、删除和拖动排序；点击才进入封面编辑，工具面板仍按需展开。
- 正面封面的底色、纸张/布纹质感、文字字体/字号/加粗/颜色、贴纸位置/大小/旋转/层级可编辑。
- 照片支持添加、替换、裁切比例、缩放和裁切位置、白边；铺满封面时自动放到底层。裁切照片复制到内页后保持裁切。
- 封面标题与手账名称同步，支持隐藏标题；其他文字保持独立。标题输入上限沿用编辑器的 40 字。
- 封面修改支持撤销、重做、恢复初始排版和自动保存；书架与翻阅使用相同结构化封面渲染。
- 图片沿用账号隔离的作品同步接口，上传图片先压缩至最长边 1600 像素；拒绝超过 10 MB、2400 万像素或无法读取的图片，保留当前封面。
- 前后端图片引用校验、归档贴纸引用、跨浏览器图片恢复和冲突合并均包含封面。旧手账无需批量迁移，首次进入封面编辑时生成结构化封面。
- 本轮仅编辑正面封面；封底、书脊和书本尺寸保持现有逻辑，无新增依赖或外部模型调用。

1. `npm test`：64 项通过，包含新增封面图片持久化、账号隔离、导出引用及非法跨页/重复 ID/裁切值校验。见 [backend-tests.txt](backend-tests.txt)。
2. `npm run check:prototype`：15 个浏览器脚本语法与入口检查、前端类型检查、10 项合并检查通过。`npm run test:frontend`：8 项通过。见 [frontend-checks.txt](frontend-checks.txt)。
3. 独立 Chrome 浏览器：13 组封面专项检查通过，页面脚本错误为零。涵盖实际控件输入、拖动、照片上传、损坏图片、刷新恢复、全新浏览器登录后的图片下载、书架/翻阅展示、撤销重做和窄屏布局。见 [browser-results.json](browser-results.json)、[browser.cjs](browser.cjs)。
