# 书页元素双击菜单 · 2026-09-10

按 Song 要求，编辑书页时双击已放置的贴纸或文字，显示复制、粘贴、删除小菜单。文字额外提供“编辑文字”，点击后沿用原位输入。这一最新交互替代此前“直接双击进入输入”；点击空白处直接写字保留。

## 行为

- 复制暂存元素快照，不立即增加副本；粘贴创建新 ID，保留字体、字号、颜色、加粗、方向、旋转或贴纸素材引用。
- 右键元素也可打开菜单；右键空白处可将暂存元素粘贴到当前页。没有可用副本时粘贴禁用。
- 删除只移除书页上的元素，保留贴纸仓库素材。粘贴和删除沿用撤销、重做、本机自动保存及账号同步。
- 跨页贴纸粘贴到另一组双页时重新绑定目标配对；目标没有配对页时取消跨页引用。数据仍为单个元素，每半页各渲染一次裁剪内容。
- 暂存副本只在当前网页会话内有效，不读写系统剪贴板；刷新、退出或切换身份后清空，粘贴前校验工作空间。可在同账号的页面或手账之间使用。
- 菜单限制在视口内；点击外部、Esc、外部滚轮、调整窗口、重绘或离开编辑时关闭。支持上下方向键移动并跳过禁用项。翻阅模式不开放编辑菜单。
