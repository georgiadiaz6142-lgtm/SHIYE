# 账号作品自动保存与恢复验收 · 2026-09-10

## 已实现

Song 确认：账号作品默认自动保存并同步，无需手动保存或逐本选择。仅访客作品首次归入账号保留选择。

- 编辑仍先写 IndexedDB，随后后台同步整个账号的手账、素材、收藏、置顶、名称和删除状态。未放进书页的贴纸也同步。
- 登录同一账号的独立浏览器自动恢复作品及图片。新浏览器账号空间从空空间恢复，避免每次生成三本不同 ID 的示例书并重复同步；访客示例不变。
- 本机工作区本身充当持久待传数据；提交前将 operationId、baseRevision 和请求快照一起写入按账号隔离的 IndexedDB 同步记录。回包丢失原样重试，确认后清理待传请求。
- 默认停止修改约 500ms 保存本机，随后约 800ms 启动同步；前台空闲每 15 秒检查新版本，网络错误按 3～60 秒退避，online 事件立即唤醒。关闭页面后不承诺后台传输；下次登录原账号继续补传。
- 同一浏览器标签页通过 Web Locks 串行同步，IndexedDB 比较写入及服务端 revision 作为兜底。不同浏览器冲突保留另一版本，并为本机编辑创建冲突副本；过时删除不能抹掉另一处新编辑。
- 输入、拖动、裁图及编辑画布期间不拉取替换画面。无冲突的本机编辑仍自动上传；需要合并时等返回书架或结束该操作再合并。
- 每个请求携带期望账号 ID，服务端与当前会话核对。切换 Cookie 后迟到的旧账号写入被拒绝，不会串号；临时身份接口故障不会当作退出登录。
- 轻量显示本机保存与同步状态，异常可点击状态查看原因并重试，没有新增日常保存按钮。

## 当前边界

当前同步目标是本机开发服务的持久目录 `.local/baidu-live-trial-20260908/works-dev/`，不是火山引擎云端。界面显示“已同步到当前服务”。未开通 TOS、数据库、公网部署或付费资源；上线时仍需生产数据库/对象存储适配与备份验收。

不能据此声称真机 Safari、多设备公网访问或离线首次打开网页已验收。首次打开/登录需要服务可访问；已加载页面可保留本机改动，待连接恢复再传。服务端图片输入仍限 10 MiB、2400 万像素，快照 JSON 限 16 MiB；超限会保留本机内容并显示错误。

图片文件按内容留存，删除书架条目不会立即回收对象文件；生产环境的孤立图片清理和存储配额属于上线前后续工作。本轮未改文字输入、字体和裁图逻辑，也未接入额外模型。
