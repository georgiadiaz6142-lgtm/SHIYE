# 翻页起落闪烁与书脊亮度修复 · 2026-09-10

## 本轮变更

Song 确认图片跟随问题已解决，继续反馈起翻/落页照片闪动，以及内侧书脊突然变亮。本轮修改 `shiye-editorial-prototype/app.js` 和 `styles.css`，保留现有曲面角度、时长、图片完整解码及相邻页缓存。

查到的具体原因：动画切片在进度 0/1 仍叠加 2.5% 固定暗色，切回静态页产生亮度差；动画层高于原书脊，覆盖阴影；原始背面还带一层旧的明暗渐变。静态 DOM 和图片快照直接交换，也有采样/字体边缘差异。

修复：

- 起落端点阴影归零，取消切片边缘额外亮线，去掉重复的旧背面光照。
- 阅读/双页编辑书脊保持在独立的翻页三维层之上，移除中心渐变中的白色高光，避免翻页盖住书脊后变亮。
- 起落各 6% 进度内，在实际 DOM 页面与动画纹理之间平滑衔接；中段继续使用原有轻量切片。原始正反面仅在端点附近显示，落页使用目标侧的布局位置，避免额外 GPU 平移。
- 两面原始内容的失败回退沿用同一套正反面位置计算，动画完成仍回到原可编辑数据。

## 量化与视觉检查

隔离本机 Chrome，1440×1000，湖景照片、胶带和花朵所在书页，比较动画进度 0 与起翻前、进度 1 与落页后。同区域平均 RGB 绝对差，范围 0–255：

| 区域 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 正向起翻纸面 | 4.81 | 0.003 |
| 正向落页纸面 | 6.53 | 0.84 |
| 起翻书脊 | 6.64 | 0.49 |
| 落页书脊 | 11.81 | 0.49 |

反向起落纸面为 0.84 / 0.66，书脊约 0.49。阈值为各区域小于 2；不是对所有设备或完全零像素差的承诺。已查看起翻 2.5%、中段、落页 97.5% 画面，照片、贴纸保留，书脊光影连续。轻微运动采样差异仍存在。真实手机/Safari与主观手感尚未验证。
