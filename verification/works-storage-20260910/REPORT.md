# 账号作品服务端保存：本机开发阶段 · 2026-09-10

已完成第一步的服务端接口和 HTTP 验收：按账号保存、读取一本完整手账及其引用图片；进程重启、重新登录后可恢复，跨账号访问被拒绝，重试不重复保存，并发旧版本不会覆盖新版本。

**当前页面仍使用原有 IndexedDB 保存流程，没有接入这些接口，不会自动上传既有作品。本轮没有接入 PostgreSQL/TOS，不代表云同步或生产存储已经完成。**

## 范围和实现

- `shared/works.ts`：版本化手账包，保留页面顺序、纸张、双页关系、跨缝贴纸、字体、竖排高度、旋转、镜像、锁定状态，以及引用的归档素材。图片使用持久 imageId，官方图片使用受约束的路径或内置素材 ID；拒绝 blob/data URL、任意外部地址和未知字段。
- `server/works.ts`：保存、读取、图片验证与引用检查；整本手账快照使用 baseRevision 乐观锁，operationId 持久去重。同一次操作换内容返回冲突；对旧 operationId 重试返回最初确认结果，不回滚当前手账版本。
- `server/work-storage.ts`：仓库与图片存储接口、本机开发适配器。元数据通过串行事务和临时文件原子替换提交，图片按账号和内容散列分区保存；文件权限 0600、目录 0700。先写图片再登记元数据；失败不发布可见的断图记录。元数据损坏会报错，不重置用户数据。
- `server/work-routes.ts` / `server/app.ts`：新增 `/api/works`，复用现有服务端登录会话。邀请码资格本身不等于账号。所有读写按服务端账号 ID 限定归属，管理员也只读取自己的作品；写操作保留同源校验，响应禁止缓存。
- 图片保存独立于百度临时抠图媒体，不调用模型，不继承一小时过期删除。原文件最多 10 MiB、最多 2400 万像素，静态 JPG/PNG/WebP，规范化为 PNG；规范化结果超过 32 MiB 会拒绝。本轮不自动缩小用户图片。

元数据和图片将在首次实际写入时创建于当前运行目录的 `works-dev/metadata`、`works-dev/objects`。新接口明确返回本机开发存储标识，没有冒充云端状态。当前真实运行目录未创建作品存储数据。

## 验证

`npm test`：**46/46 通过**，包括原有 40 项及新增 6 组：

1. 新存储实例读回完整双页手账、归档贴纸与透明图片，验证文件权限。
2. 重复图片上传／保存不重复创建，图片 ID 不可换内容，两个并发写入只有一个成功，旧操作重试不回滚。
3. 缺少图片、引用其他账号图片、对象写入失败、图片损坏均不提交手账。
4. 模拟元数据提交失败保留旧版；损坏文件读取／写入失败后内容不变。
5. 拒绝伪造 ownerId、临时图片地址、缺失素材与断开的跨页引用。
6. 真实 HTTP 覆盖普通账号 A/B、游客／仅邀请码拒绝、跨域写入拒绝、体积上限、无效图片、服务关闭并重新创建后重新登录恢复及退出失效。

证据：[backend.txt](./backend.txt)、[live-results.json](./live-results.json)、[restart-results.json](./restart-results.json)。

当前 4176 已加载接口。隔离 Chrome 确认首页和邀请登录弹窗正常显示，匿名作品接口返回 ACCOUNT_REQUIRED，管理接口仍禁止匿名访问，百度调用配置保持不变。重启前确认没有在途任务，账号／邀请码／环境文件摘要比较一致。实际管理员密码未用于测试；测试采用虚构账号和合成图片，真实百度调用、云资源开通、真实作品上传均为 0。

首次重启保护检查因进程命令使用 Node 绝对路径而停止，没有发送终止信号。核实准确命令后正常重启，最终只读检查通过。浏览器验证按现有 agent-browser-verify 技能执行；agent-browser 命令不可用，沿用已安装 Playwright + Chrome，不安装新工具。

## 明确未完成的部分

- 页面保存流程、持久重试队列、主动导入确认、第二个浏览器恢复界面，以及素材仓库独立同步尚未接入。
- 当前冲突返回 409 并保留服务端新版本；客户端合并／另存冲突副本将在下一步实现。
- 本机 JSON 适配器仅用于单进程开发验证，不可把它放到 veFaaS 临时目录当生产数据库；PostgreSQL、TOS、生产账号／会话持久化和真实云故障恢复仍需接入验证。
- 当前不提供作品删除、独立素材删除、存储额度和未引用图片回收。图片写入后元数据提交失败可能留下不可见的孤立文件；本机阶段不擅自删除文件，云接入前需要上传会话过期回收和配额。
- 只验证了普通进程重启及模拟 I/O 失败，没有验证硬盘损坏、系统断电或多实例一致性。官方素材跨设备恢复还依赖发布相同版本的素材资源。

下一步：前端显式选择作品后，转换本机图片引用、提交依赖图片与手账包，显示保存状态；失败保留本机并使用相同操作 ID 重试。接云前继续按 Song 决定延后开桶，以低成本够用为选型约束。
