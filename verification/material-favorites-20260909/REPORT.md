# 素材、收藏与创作入口验收 · 2026-09-09

## 实际改动

- 原“我的收藏”改为“我的素材”，新增“收藏”标签，保留“拾页素材”。已有素材不会自动变成收藏；点击三点菜单的收藏后才进入收藏板块。
- 自有素材的小号“用于创作”按钮去掉箭头，后接三点菜单：置顶／取消置顶、收藏／取消收藏、删除。沿用原书架菜单的原生弹层、外部点击及 Escape 关闭方式。
- 置顶优先，其余按制作时间倒序。新增 `createdAt`；旧素材未记录时间，按原数组加入顺序倒排。取消收藏保留素材；删除需要确认，归档图片以保留手帐中的引用。
- 本地裁切与自动抠图保存均归入“我的素材”，不自动收藏。已删除素材的来源会话也计入完成记录，避免重新进入抠图恢复旧结束页。
- 首页主按钮改为“开始创作”，进入书架。书架原右上角放置两个较小、同尺寸的按钮，上方“新建手帐”、下方“创建贴纸”。
- 移除本地贴边操作区的“照片仅在本机处理”。
