# 按需工具面板与手势翻页 · 2026-09-10

【已完成】

- 进入编辑、选中元素及直接在书页输入文字时，不展示右侧面板，也不占位。只有主动点击贴纸、文字、纸张、页面才打开。
- 面板打开后保持打开；继续输入、插入贴纸、应用 AI 文案不自动收起。再次点击当前工具或关闭按钮可收起。选中文字后主动打开文字工具，显示当前文字的属性。
- 底部工具栏桌面高度由约 68px 缩至约 46px，宽度同时收紧；触屏按钮保留至少 44px 高度。
- 书页按实际可用宽高等比例放大，移除原先 420/440px 的显示尺寸上限；手机浮动箭头不再重复占用布局宽度。页面内容及相对位置数据不变。
- 编辑模式：空白处单击输入，明显横向滑动翻页；鼠标与手机单指共用。文字、贴纸及控制柄上的手势仍用于编辑，纵向拖动和多指空白手势不翻页。
- 触控板横向 wheel 手势翻页，累计阈值及惯性锁避免一次手势连翻多页；纵向滚动、缩放手势、输入框及工具面板滚动不翻页。
- 阅读模式可从书页中部横拖翻页，保留软纸动画、单击选页、点击封面和箭头操作；双页模式按原有配对翻页。

【验证】

- `browser.cjs`：11 组隔离 Chrome 检查通过，包含面板状态、桌面及 390/320px 布局、鼠标拖动、水平 wheel/惯性、Chrome 原生触摸事件、单双页、阅读点击、键盘删除/撤销、同步刷新。
- `element-menu-regression.cjs`：9 组回归通过，包括双击菜单、原位输入、复制粘贴、跨页裁剪、删除撤销及账号切换清空剪贴板。
- `npm run check:prototype`：脚本语法与 10 项合并检查通过；`ai-copy.js` 语法及 `git diff --check` 通过。
- 桌面单页/双页、手机开/关面板截图已查看。最终结果为 `browser-results.json` 和 `regression-browser-results.json`；`failure.png` 保留的是早期测试夹具调试画面（滑动起点被已有文字覆盖、直接修改布局未走保存），不代表最终验收状态。
- `live-assets.json`：4176 的三个前端文件均 HTTP 200，且与本地一致。

【范围与限制】本轮产品改动限 `app.js`、`styles.css`、`ai-copy.js` 的上述交互；保留其他已有未提交内容。没有真实模型调用、账号配置更改或用户浏览器作品操作。触控板以标准 wheel 事件、手机以 Chrome 原生触摸模拟验证，未进行物理设备或 Safari 手感验收。
