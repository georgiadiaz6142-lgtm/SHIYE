## 当前使用入口

打开原 `http://127.0.0.1:4176/`，贴纸工坊 → 选择照片或山湖示例 → 粗圈一个物体并完成圈选 → **试用自动贴边** → **计算贴边**。在照片下方点“保留／排除”后点击照片添加提示点，再重新计算。绿色覆盖表示算法选中的保留区域；确认后沿用原透明预览、白边、收藏和用于创作流程。

一个选区对应一个独立结果，多个选区分别计算；不把这些人工提示的选区说成自动发现主体。修改圈选或提示点后旧结果失效，全部选区计算完成且没有未完成圈线时才允许确认。提示点支持撤销和清空；原裁切撤销也包含提示点。结果有 `classical-segmentation` 来源元数据。

原手工小剪刀保留，通过“返回原来的手工裁切”切回。百度自动工坊、原本地作品保存结构、米白首页、绿色书本、12 纸样和软翻页保留。未恢复木桌或画笔试验。手机加载照片后主动将照片移回可见区域，修复新增内容后保留旧滚动位置导致的点选问题。

## 实现与计算边界

- `edgecut-core.js`：调用真实 `cv.grabCut`，固定 5 次迭代和随机种子。粗圈内部初始化为可能前景，周边为可能背景，远离圈选的区域为确定背景；周边不确定带为图像宽高归一化的 4%。保留点可扩大初始化范围。提示点只标记小邻域，不描绘输出轮廓。
- `edgecut-worker.js`：库按需加载到浏览器 Worker；20 秒超时，取消、换图或离开后终止／忽略迟到结果。算法在本机运行，不访问模型 API。
- `edgecut.js` / `edgecut.css`：在已有圈选页面增加试验入口、照片旁快捷按钮、点提示和真实 mask 叠加。缓存只在当前图片会话内，不覆盖其他候选。
- 最大分析边长 720 像素，掩膜放大回原工坊规范化照片尺寸。沿用原工坊最多 1400 边长和 JPEG 规范化路径，因此不宣称与上传文件逐字节相同。输出 RGB 来源于规范化照片，透明度来自 GrabCut；不存在生成式重绘或用圈线 Canvas clip 代替分割。
- 为试验复用现有本地贴纸 data URL 保存路径，没有更改 IndexedDB schema 或迁移旧作品。不会读取此前百度临时照片来自动处理；只处理当前主动选择的照片。
- 后端只增加明确的静态文件白名单。原 4176 服务正常退出后以原配置、原计数目录重启，未重置百度次数、期限或密钥。实验期间没有百度请求或照片上传。

## 实际验证

1. [算法结果](./algorithm-results.json)：4 项检查通过，包括已知圆形图像真正产生曲线 mask（IoU 1.0）、排除点改变结果、后加保留点优先、无效提示拒绝。合成图只用于工程校验，不作为真实照片质量成绩。
2. 真实项目照片：咖啡初始、咖啡修正、山湖船体修正共 3 次真实 GrabCut 运算，分析尺寸 720×480，本机 Node/WASM 样例耗时约 389–461 ms。此时间不包含浏览器库加载、解码与 UI 操作，不能当作全流程 P95。
3. [新浏览器流程 run-03](./run-03/results.json)：3 组通过。实际 Worker 运算、提示点改变 mask、撤销恢复、多个选区、改圈失效、取消、换图防迟到、透明预览、收藏刷新、放入新手帐并刷新恢复、模拟手机布局和坐标对齐。透明测试结果包含 10961 个全透明像素、22414 个不透明像素。外部请求、HTTP 写请求和页面错误均为 0。
4. [原小剪刀回归](../stage1-20260908/grabcut-original-regression-02/results.json)：4 组通过，原圈选、调整、撤销、确认、原页收藏回填和模拟手机操作保留。
5. [后端回归](./backend-tests.txt)：严格 TypeScript 编译及原 20 项后端测试通过，供应商均为隔离模拟，无真实付费请求。原数据合并 10 项通过；前端新增文件语法检查通过。

## 人工检查与未完成项

已查看咖啡和船体的原图／结果并排图，以及桌面、手机和透明预览截图。算法能算出杯口、船身的非矩形边缘，但咖啡仍有细碎背景残留，船体结果有少量离散误选；不能称为干净成品或“点两下必定成功”。目前没有自动清理碎片，以免删除应保留的细小部分。

当前仅用项目自带非敏感样图作本地检查，没有检查或转发 Song 的真实私人照片。人物发丝、低对比相邻物体、用户反馈的房子与地面、真实手机和 Safari 尚未验证。720 像素分析会损失细边缘；需要更多纠正点或仍失败的情况必须如实展示。

自动发现主要物体、50 张正式样本、90% 纠错目标和正式上线均未完成。此次实验未把 GrabCut 结果记为 AI 模型验收，不改变原第一阶段标准。用户已保存的作品仍在浏览器原 origin，代码归档不等于作品备份。
