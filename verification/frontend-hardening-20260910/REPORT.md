## 节点与范围

Song 授权先保存节点，再做前端质量补齐。开发分支 `feat/frontend-hardening-20260910`；前置节点为 [恢复说明](../../archive/20260910-213055-before-frontend-hardening/README.md)。归档包含 1649 个文件及当时未提交修改，逐文件 SHA-256 已验证。未包含密钥、私人运行数据、用户作品、依赖或旧归档；此节点不是用户数据备份。

沿用原生 HTML/JavaScript/CSS 与单套 Express 服务，不迁移框架、不增加依赖、不改已有翻页引擎。本轮是前端加固的第一阶段，不代表所有前端技术债或上线条件均已解决。

## 过程中发现并修正

1. 首次浏览器运行新增页面管理脚本被静态白名单拦截，页面初始化失败。已补两个精确白名单条目，并加入自动入口检查，最终回归通过。
2. 新增刷新断言最初仅等待旧的同步标签，未等待 500ms 本机保存延迟，导致提前刷新。测试改为等待本机持久化，再等待服务同步，保留实际恢复断言。
3. 复制的翻页测试缺少截图子目录，补齐目录后运行通过。
4. 较早的同步/文案测试仍假设双击文字直接编辑、编辑自动打开工具面板；现界面需从双击菜单选择编辑，并主动打开文字面板。已按当前确认交互更新本轮测试副本，保留原有业务断言；重复文案入口改为明确选择第一个工具入口。

失败轮次 JSON 保留在本目录 `*-failed.json`，没有计入通过结果；旧验收脚本和报告未覆盖。
